# Mosvera

**A declarative runtime for aesthetic intent in AI-native systems.**

Mosvera defines aesthetic primitives (templates, palettes, modifiers, compositions) and compiles them into design tokens, CSS variables, and provider-specific outputs through a provider-neutral canonical model. Systems consume Mosvera through its local runtimes and MCP server, with no hosted runtime dependency.

> **This repository is a signpost.** Mosvera began here as one combined repo and has since split into focused repos under the [mosvera GitHub organization](https://github.com/mosvera). Active development, the specification, and all releases live there. This repo stays public and readable as the historical combined snapshot, and it no longer receives code changes.
